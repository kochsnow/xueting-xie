# Xueting Xie — Personal Homepage

An English personal profile for Xueting Xie, Assistant Finance Manager at Bank of China, Dongguan Branch.

## Hosting

Static HTML, with no build dependencies. Configure GitHub Pages to deploy from the root of the `main` branch.

## Editing

Edit `index.html` to update the profile, contact details, and page styling. The research section describes annotation contributions, not publication authorship. The education section describes a CPA-oriented minor, not CPA licensure.

## Local preview

Run `python3 -m http.server 8765` in this directory and visit `http://localhost:8765`.
